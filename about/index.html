How it works

Walk in.
Start talking.

Austin.chat turns the city into a live conversation. Every grocery store, library, bar, and campus is a chat room — open only to people who are actually there.

No login required No history saved Free forever Austin, TX
1
Choose your world

Select a category — or browse them all

Austin.chat organizes the city into over 20 categories: H-E-Bs, Starbucks, libraries, bars, campuses, transit centers, parks, hospitals, and more.

Toggle a category on and its locations light up on the map. Everything else steps back. You see only what matters to you right now.

2
Your city, mapped

Every location becomes a geofenced chat room

Each spot on the map — an HEB, a university, a bar — has an invisible geofence drawn around it. When you're physically inside one, it glows and the chat opens.

Spots from a different active category appear in muted gray so you always know which world you're in. No confusion, no clutter.

📍

The orange zone is Huston-Tillotson University; the purple is H-E-B East 7th. Each geofence is sized to match the actual footprint of that location.

3
You're in

Cross the threshold — the chat opens automatically

No buttons to tap. The moment your GPS puts you inside a geofence, a bottom sheet slides up with the chat for that location. A YOU'RE HERE badge confirms it's live.

Messages are ephemeral — nothing is stored, no account is needed. Walk out and the conversation is gone. That's the point.

4
Reach across the city

Chat with every H-E-B from yours

Your home location is your anchor. From there you can open any other spot in the same category — tap H-E-B Riverside and you're "visiting from your spot." Your messages arrive labeled from H-E-B East 7th so context is never lost.

It's like shouting across the aisle, except the aisle spans the whole city. Ask if they have eggs. Warn about the checkout line. Say hi.

🔗

One network per category. Every H-E-B in Austin shares a live chat layer. You're anchored to your spot but connected to the whole chain.

5
More than chat

Every spot carries useful info

Tap the Info tab in any bottom sheet and you get hours, address, quick links to Waze for navigation, and a Reddit thread for that location — all without leaving the map.

Spots can also carry poll tabs for community questions and ad banners for local businesses — keeping the whole thing self-sustaining without paywalls or subscriptions.

Under the hood

Built on open infrastructure — zero ongoing cost

Every piece of the stack is either open-source or has a generous free tier. No servers to manage, no bills to pay, no vendor lock-in.

🗺️

MapLibre GL JS

Open-source WebGL map renderer. Smooth 3D tilt, satellite imagery, and custom circle layers for geofences — all client-side.

Free & open source
🌐

OpenFreeMap

OpenStreetMap-based tile server with no API key required. Vector tiles served from the edge — fast, free, and attribution-only.

Free · no key needed
⚡

Supabase Realtime

Broadcast-only WebSocket channels power the live chat. Messages are never written to a database — Realtime is the pipe, not the store.

Free tier · no DB writes
📄

GitHub Pages

The entire app is static HTML, CSS, and JavaScript committed to a public repo and served by GitHub Pages. No build step, no CDN config.

Free hosting
📡

Browser Geolocation API

Standard Web API — no third-party SDK, no tracking service. Coordinates stay on-device and are only used to evaluate geofence proximity.

Built into the browser
🔒

No accounts, no data

Anonymous handles are generated locally. Nothing is persisted. No emails, no passwords, no analytics beyond what GitHub Pages logs by default.

Zero PII stored
🟢

Ready to deploy at zero cost

Fork the repo, drop in your own hotspots.json, and push to GitHub Pages. Add your Supabase project URL (free tier supports thousands of concurrent Realtime connections). That's it — your city's version of Austin.chat is live.
